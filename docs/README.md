# Documentation

Cette documentation suit le modèle [Diátaxis](https://diataxis.fr/) : quatre besoins de
lecture distincts, quatre dossiers distincts. Avant d'écrire ou de chercher une page,
identifiez le besoin :

| Dossier | Besoin du lecteur | Quand y aller |
| --- | --- | --- |
| [`tutorials/`](tutorials/) | Apprendre en faisant | Vous découvrez l'outil, vous voulez un premier résultat guidé pas à pas. |
| [`how-to/`](how-to/) | Réaliser une tâche précise | Vous savez déjà utiliser l'outil, vous cherchez comment faire une chose précise. |
| [`reference/`](reference/) | Retrouver une information exacte | Vous cherchez la valeur d'un paramètre, la responsabilité d'un module. |
| [`explanation/`](explanation/) | Comprendre un choix | Vous voulez savoir *pourquoi* c'est fait ainsi plutôt que comment le faire. |

Ces quatre types ne se mélangent pas : un tutoriel n'explique pas les alternatives
écartées, une explication ne donne pas d'instructions numérotées. Si une page hésite
entre deux quadrants, c'est qu'elle devrait être scindée.
